Authentication & Vault Keys

The SHOORA AI API authenticates requests using API keys issued directly from your configured Dynamic Pricing Matrix or allocated via the Enterprise Inventory Key Vault.

Pass your key in the Authorization HTTP header. Vault keys map to your configured Agent type, Foundation Model, and Precision Accuracy Level.

bash
curl https://api.shooraai.tech/v1/models \ -H "Authorization: Bearer sk_live_your_vault_key"

Rate Limits & Daily Usage Tiers

Rate limits are determined dynamically by your selected Daily Capacity Tier (1k to Unlimited Enterprise). Headers specify remaining quota.

Configured Usage Tier Daily Request Limit Burst Limit (RPM)

10k Tier 10,000 req/day 600 RPM
50k Tier 50,000 req/day 3,000 RPM

Endpoints

POST /v1/agent/execute

Executes a specialized AI Agent (Code Architect, Legal Summarizer, Medical AI, etc.) with specified model foundation and precision level.

Request Example
curl https://api.shooraai.tech/v1/agent/execute \ -H "Content-Type: application/json" \ -H "Authorization: Bearer sk_live_your_vault_key" \ -d '{ "agent": "omni-super-agent", "model": "shoora-ultra-max-1.5m", "accuracy_level": 5, "prompt": "Analyze dataset and output structured JSON execution plan." }'

POST /v1/embeddings

Generate high-dimensional vector embeddings for semantic search, retrieval augmented generation (RAG), and agent memory clusters.

Request Example
curl https://api.shooraai.tech/v1/embeddings \ -H "Content-Type: application/json" \ -H "Authorization: Bearer sk_live_your_vault_key" \ -d '{ "model": "shoora-embed-large-v3", "input": "Financial query vector indexing." }'

Error Codes & Troubleshooting

SHOORA AI returns standard HTTP response codes alongside descriptive JSON error payloads to assist with immediate debugging.

Status Code Meaning Resolution
200 OK Successful execution Response payload ready in choices object.
401 Unauthorized Invalid or Missing Vault Key Ensure your Bearer token matches your purchased API key.
429 Too Many Requests Daily Capacity Limit Exceeded Upgrade your usage tier or configure burst buffer.
500 Gateway Error Internal cluster failover Automatic failover engaged. Check System Status.

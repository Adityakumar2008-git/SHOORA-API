Authentication

The SHOORA AI API uses API keys for authentication. Visit your dashboard to retrieve the API key you'll use in your requests.

Remember that your API key is a secret! Do not share it with others or expose it in any client-side code (browsers, apps).

bash
curl https://api.shooraai.com/v1/models \ -H "Authorization: Bearer $SHOORA_API_KEY"

Rate Limits

To ensure platform stability, we enforce rate limits at the organizational and user levels. The limits depend on your current pricing tier.

Tier Requests per Minute (RPM) Tokens per Minute (TPM)
Developer 500 100,000
Startup 5,000 2,000,000
Enterprise Custom Custom

Endpoints

POST /v1/chat/completions

Creates a model response for the given chat conversation.

Request Example
curl https://api.shooraai.com/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer $SHOORA_API_KEY" \ -d '{ "model": "shoora-turbo-v2", "messages": [ {"role": "system", "content": "You are a helpful assistant."}, {"role": "user", "content": "Hello!"} ] }'
